# Refresh the external skills list

Follow the source audit and refresh procedure in the Agents checkout at `~/Repos/callumflack/agents/docs/external-skills.md`. The source list and editorial decisions live there. [Agents source audit and refresh procedure](https://github.com/callumflack/agents/blob/master/docs/external-skills.md).

1. Update [External skills](../src/content/docs/external-skills.md) and the Obsidian External skills note together. Keep private inventory details in the vault and public source links in the standalone edition.
2. If the overview changes, sync both editions using their existing catalogue commands.
3. Compare the shared text, run `npm run build`, and check the rendered page and the entry links from the homepage and Skills index.
