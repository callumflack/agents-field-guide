title: "The Topology of an LLM Agent Loop With Tool Use"
lastUpdated: 2026-11-11
---

Philip Zeyliger breaks an agent into its model, the loop that calls it, and the tools it can use. Each can run in a different place. Those choices affect cost, responsiveness, what data reaches the model, and what the tools can access.

Use the distinction to compare two agent setups. Locate the model, the process running the loop, and the tools before deciding what a particular setup can do and what it can affect.
