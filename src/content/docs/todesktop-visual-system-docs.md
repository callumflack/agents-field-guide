Dave Jeffery shows how ToDesktop documents flows across packages. Choose an action such as inviting a user or starting a build, then follow what passes between packages. The docs also show phases, data objects, and failure paths.

The visual page reads from a JSON document. Agents can read the same flow description when working on a related feature or bug.
