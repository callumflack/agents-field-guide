These six agent roles come from [Sutter Hill’s Intent Specialists repository](https://github.com/sutterhill/intent-specialists).

Browse the [Intent collection in the Skills index](/skills/#skills-i-publish).

## [Lead](https://github.com/sutterhill/intent-specialists/blob/main/lead.md)

For work that needs several agents coordinated through a shared spec and task notes.

[Install `intent-lead`](https://www.skills.sh/callumflack/skills/intent-lead).

## [dev bro](https://github.com/sutterhill/intent-specialists/blob/main/dev-bro.md)

For implementing a scoped feature or fix and checking that it works.

[Install `intent-dev-bro`](https://www.skills.sh/callumflack/skills/intent-dev-bro).

## [Diagram Maker](https://github.com/sutterhill/intent-specialists/blob/main/diagram-maker.md)

For drawing an interactive diagram of a system or flow in Intent.

[Install `intent-diagram-maker`](https://www.skills.sh/callumflack/skills/intent-diagram-maker).

## [LukeW Interface Designer](https://github.com/sutterhill/intent-specialists/blob/main/lukew-interface-designer.md)

For getting advice on a specific interface decision grounded in Luke Wroblewski’s [work](https://www.lukew.com/ff/2171/ask-lukew-in-your-ai-tools).

[Install `intent-ui-designer`](https://www.skills.sh/callumflack/skills/intent-ui-designer).

## [State Machine Auditor](https://github.com/sutterhill/intent-specialists/blob/main/state-machine-auditor.md)

For tracing an invalid state back to the underlying code, especially after cancel, retry, or a late response.

[Install `intent-state-machine-auditor`](https://www.skills.sh/callumflack/skills/intent-state-machine-auditor).

## [Vulnerability Scanner](https://github.com/sutterhill/intent-specialists/blob/main/vulnerability-scanner.md)

For checking whether a suspected vulnerability has a real path from attacker input to impact.

[Install `intent-security-review`](https://www.skills.sh/callumflack/skills/intent-security-review).
