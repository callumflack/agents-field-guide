**Start with code and enforceable checks. Layer on verification. Use prose where judgment remains.**

1. Build trust into the codebase.
2. Leave patterns worth copying.
3. Turn corrections into executable checks.
4. Contain nuance behind better APIs.
5. Enforce the boundaries you name.
6. Fix the cause. Retire the workaround.
7. A comment cannot enforce a rule.
8. Let the agent drive the real app.
9. Review verification artifacts.
10. Invest heavily in verification.
11. Layer tests, models, and proofs.
12. Fix the loop before you scale it.
