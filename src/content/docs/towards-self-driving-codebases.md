---
title: "Towards Self-Driving Codebases"
lastUpdated: 2026-11-11
---

Dan Robinson argues that agents make mistakes in the parts of a system they cannot exercise. If they cannot run an integration end to end or reproduce a race, a code change can look finished without evidence that it works.

Robinson proposes using real bug fixes to decide what the development environment needs. Track what made a bug hard to reproduce or a fix hard to verify, then improve the environment where those gaps recur.
