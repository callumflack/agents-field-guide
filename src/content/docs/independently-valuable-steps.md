---
title: "Work in independently valuable steps"
lastUpdated: 2026-11-11
---

James Cowling describes a failure he saw at Convex. When the team asked an agent to build the ideal end state of a hard project in one go, it could go far down a design path that was hard to unwind.

Choose one deliverable that would still be useful if the rest of the project stopped. Have the agent build it, inspect the result, and use what you learned to decide the next step.
