---
title: "Give the agent a way to verify its work"
lastUpdated: 2026-11-11
---

Addy Osmani argues that as agents produce code faster, proving it works becomes the bottleneck. Give the agent a check it can run and interpret while it works. A browser test can exercise a user flow, while a property test can check an invariant across many inputs.

Use human review to decide what the software should do, what can go wrong, and what evidence is enough for the change.
